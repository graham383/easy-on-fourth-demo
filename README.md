# Easy on Fourth (concept demo)
Static site. Everything served from `public/` (index.html + images/). No build step.
Deploy: drag this folder into the Vercel dashboard (Framework: Other, Output Directory: public),
or push to a git repo connected to Vercel. Image files are normal binary assets in public/images.
Images: WebP q82 + AVIF q58, generated from the lossless originals, never enlarged.
